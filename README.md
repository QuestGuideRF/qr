# 🔲 Генератор QR-кодов

Современный веб-генератор QR-кодов с красивым интерфейсом и расширенными возможностями настройки.

## ✨ Возможности

- 📝 **Генерация QR-кодов** из любого текста или ссылки
- 🎨 **Настройка внешнего вида**: размер и цвет QR-кода
- 💾 **Скачивание** готовых QR-кодов в формате PNG
- 📱 **Адаптивный дизайн** для всех устройств
- ⚡ **Мгновенная генерация** без перезагрузки страницы
- 🔍 **Автоматическое распознавание URL** с быстрой генерацией
- 💾 **Сохранение настроек** в браузере
- 🎯 **Валидация данных** и обработка ошибок
- 📊 **Информация о QR-коде** (размер, тип, количество символов)

## 🚀 Быстрый старт

1. **Скачайте проект** или клонируйте репозиторий
2. **Откройте `index.html`** в любом современном браузере
3. **Введите текст или ссылку** в поле ввода
4. **Настройте параметры** QR-кода (размер, цвет)
5. **Нажмите "Создать QR-код"**
6. **Скачайте результат** нажав на кнопку "Скачать QR-код"

## 🔧 API и интеграция

### QRCode.js API
```javascript
// Основные параметры генерации
const options = {
    width: 300,                    // Ширина в пикселях
    height: 300,                   // Высота в пикселях
    color: {
        dark: '#000000',           // Цвет QR-кода
        light: '#FFFFFF'           // Цвет фона
    },
    errorCorrectionLevel: 'M',     // Уровень коррекции
    type: 'image/png',             // Тип изображения
    quality: 0.92,                 // Качество
    margin: 2                      // Отступы
};
```

### Локальное хранение
```javascript
// Сохранение настроек
localStorage.setItem('qr-generator-settings', JSON.stringify(settings));

// Загрузка настроек
const settings = JSON.parse(localStorage.getItem('qr-generator-settings'));
```
